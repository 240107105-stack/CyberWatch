# Проверка версии 2.0

Проверено 2 ноября 2026 года на macOS с Python 3.14 и Tk 8.6.

## Автоматические проверки

`python3 -m unittest discover -s tests -v` — 65 тестов, все прошли.

Проверки охватывают CLI, совместимость старой схемы SQLite, сохранение настроек,
историю статусов и заметки, три правила обнаружения, временные границы,
IPv4/IPv6, ошибочные даты, повторный импорт, частичные строки и ротацию лога,
экранирование отчётов и защиту файла базы от перезаписи при экспорте.

## Оконная проверка

Программно проверены все шесть разделов при размерах 1420×900 и 1180×760:
переходы навигации, размещение элементов, демо, три сигнала, повторная проверка,
поиск, подробности события, сохранение заметки, изменение статуса, HTML/CSV,
добавление строк наблюдаемого файла и автоматическая детекция, остановка
наблюдения, закрытие и повторный запуск с восстановлением настроек.

Доступ к снимку экрана через macOS не был предоставлен. Проверка геометрии
виджетов и обработчиков выполнена в настоящем окне Tkinter с временной базой.

## Совместимость рабочей базы

Предварительная миграция выполнена на отдельной копии существующей базы:
73 события и один сигнал сохранены, прежние значения и статус совпадают,
`PRAGMA quick_check` возвращает `ok`.

Рабочие данные не заменяются демо-набором. Перед обновлением проекта сохраняется
согласованная копия базы через SQLite backup и копия прежних исходных файлов.

## Воспроизведение

```bash
python3 -m unittest discover -s tests -v
python3 main.py --database /tmp/cyberwatch-check.db --demo --check --report /tmp/cyberwatch-check.html
```

Для новой отдельной базы ожидаются 21 событие и три сигнала. Второй запуск
добавляет ноль событий и ноль сигналов. Для ручной проверки следуйте `DEMO.md`.
